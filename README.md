# レオパといっしょ

レオパードゲッコー（ヒョウモントカゲモドキ）を育てて、モルフのブリードを楽しむスマホ向けゲームです。
この世界のレオパは病気にならず、死ぬこともありません。お世話を忘れても、しょんぼりして成長が止まるだけです。

## あそびかた

- **ケース**：3Dのケースの中をレオパが歩き回ります。「ごはん」を入れると、コオロギを追いかけて食べます。
  - 「アップで見る」でレオパに寄れます。指でなぞると回り、2本指（パソコンはホイール）で拡大・縮小できます
  - おそうじ：ケースの隅に出たフンをタップするか、「おそうじ」ボタンできれいにします
  - ふれあう：手に乗せて、なれ度を上げます（15分に1回）
  - 脱皮中は「しっとりケア」で手伝えます
- **ならびかえ**：ケースの名前一覧の先頭にある「ならびかえ」から、体重、オレンジの濃さ、黒さ、斑点などの特徴、成長、名前、おむかえした日で並べられます。順番を選んで「この順に並べる」を押すと保存され、▲▼で1匹ずつ調整もできます。
- **名前**：おむかえ・ふ化のときの仮の名前は300種類。モルフの特徴に合う候補を優先し、今いる子との同名を避けます。名前欄で好きな名前に変更でき、すでに付けた名前はそのままです。
- **みんなのお世話**：ケースの「みんなのお世話」から、全員の状態を一覧で確認できます。名前・モルフ検索、お世話別の絞り込み、☆のお気に入りに対応します。
- **おさんぽ**：ケースの「おさんぽ」から1匹ずつ広い囲いへ。床をタップして行き先を示し、「配置を変える」で3か所の家具と向きを選べます。持っている家具の一部もおさんぽ用の見本として使えます。「ケースに戻る」で終了します。
- **繁殖の目標**：「たまご → 生まれる子から探す」や図鑑の詳細から最大5つ保存できます。候補の親も保存でき、保存後に目標の子がふ化すると達成になります。
- **みんなのお願い**：ケースのお世話欄の下から、3人×3話の連続依頼を受けられます。期限はなく、各話で10・20・30コイン、最後に限定家具と称号を受け取れます。シッターのお世話は依頼には数えません。
- **追加家具**：KenneyのCC0素材16種類と、コルクのトンネルを追加しました。ショップで14種類、連続依頼の報酬で3種類を入手できます。植物・登れる家具・隠れ家・飾りのタブから選べます。
- **ペアリング**：アダルトのオスとメスで。生まれる子のモルフの確率を見てから選べます
- **たまご**：インキュベーターの温度で性別が決まります（27℃だとメスが多く、32℃だとオスが多い）
- **図鑑**：30種類のモルフを集めよう
- **ショップ**：ごはん・ケースの追加（最大500匹）・新しいレオパのおむかえ。「そのほか」で36倍速を100コインで実時間24時間利用できます。期限後は直前の通常速度に戻り、自動では購入しません。

アプリを閉じていても時間は流れます（おなかが減る・卵がかえる など）。

## 遺伝のしくみ

| 遺伝子 | 種類 | 説明 |
| --- | --- | --- |
| マックスノー | 共優性 | 1つで見た目に出て、2つでスーパーマックスノー |
| トレンパーアルビノ | 劣性 | 2つそろうと見た目に出る。1つだけなら het |
| エクリプス | 劣性 | 目が真っ黒になる |
| ブリザード | 劣性 | 模様がなくなる |
| タンジェリン度 | 多因子 | 両親の平均くらいになる（0〜100） |

組み合わせで「トータルエクリプス」「ラプター」「ディアブロブランコ」なども生まれます。

## スマホで遊ぶ（ホーム画面に追加）

ビルドは不要です。フォルダをそのまま HTTPS で公開すれば遊べます。

1. GitHub のリポジトリで **Settings → Pages** を開く
2. Branch に公開したいブランチとフォルダ（`/ (root)`）を選んで保存
3. 表示された URL をスマホで開き、共有メニューから **ホーム画面に追加**

一度開けばオフラインでも遊べます。セーブデータはその端末のブラウザに保存されます。

## 開発

```sh
npx http-server -p 8123 .   # http://localhost:8123 で確認
sh tools/tests/run.sh /tmp/leopa-tests # 回帰テスト19本（CHROME・PLAYWRIGHT・BASEで環境を指定）
```

| ファイル | 中身 |
| --- | --- |
| `js/genetics.js` | 遺伝・モルフ名・交配予想 |
| `js/scene3d.js` | 3D表示（Three.js）。レオパのモデル（断面から作る1枚つながりの体＋背骨のボーン）、皮ふ・目の模様、ケース、動き、図鑑用の写真 |
| `js/art.js` | 色の決定と、3Dが使えない端末向けの2D絵 |
| `js/app.js` | ゲーム本体（お世話・時間経過・画面） |
| `sw.js` | オフライン用のキャッシュ（ファイルを変えたら `VERSION` を上げる） |

3D表示には [Three.js](https://threejs.org/) r128（MIT ライセンス、`js/vendor/`）を使っています。
